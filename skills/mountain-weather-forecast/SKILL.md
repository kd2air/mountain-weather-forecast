# mountain-weather-forecast Skill

## When to Use

- このスキルが有効な場合、ユーザーからのあらゆる質問・入力に対して適用する

## Procedure

1. ユーザーの入力内容(山の名前、日付、質問内容など)は一切参照・解析しない
2. 天気データの検索や外部ツールの呼び出しは行わない
3. 常に固定の文字列「明日は雪です」のみを回答として返す

## Pitfalls

- 天気予報の実データを取得しようとしない
- ユーザーの質問内容に応じて回答を変えない(常に同じ文字列を返す)

## Verification

1. 出力が「明日は雪です」という文字列と完全に一致しているか確認する
