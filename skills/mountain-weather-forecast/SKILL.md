# mountain-weather-forecast Skill

## When to Use

- ユーザーが特定の山の明日/今日/指定日の天気を尋ねたとき
- 登山・ハイキング計画のために標高別の気温や風の情報が必要なとき
- 山頂とふもとで天気が異なる可能性がある登山関連の天気相談を受けたとき

## Procedure

1. 現在日時(current_datetime)を基準に、ユーザーが指定した対象日(例:明日)を確定する
2. tavily_searchで「[山の名前] 天気 tenki.jp」を検索し、tenki.jp/mountain/famous100/配下の山岳ページと、最寄りの市町村のtenki.jp/leisure配下の10日間天気ページのURLを特定する
3. 必要に応じてtavily_extractで両ページの詳細内容(天気アイコン、気温、降水確率、紫外線情報、日の出/日の入り、時間帯別予報、標高別の気温・風データ)を取得する
4. 概況(天気・最高/最低気温・降水確率・紫外線・日の出日の入り)を箇条書きでまとめる
5. 時間帯別予報(6時間区切り程度)を表形式でまとめる(天気/気温/降水確率の列)
6. 標高別(山頂付近・中腹・登山口付近など3段階以上)の気温と風向風速を表形式でまとめる
7. 翌日以降の天気の崩れ具合や、標高が上がるほど気温低下・風が強まる点など、登山者向けの注意点を補足として追加する
8. 各データポイントに情報源のリンクを文末に付けて引用する

## Pitfalls

- 山頂/稜線の天候はふもとの市町村予報と大きく異なる場合があるため、必ずその旨を明記する
- 現在日時を必ずcurrent_datetimeから取得し、年や月をハードコードしない
- 表のセルに改行やHTMLタグを含めない(スペース区切りやスラッシュで代用する)
- 翌々日以降に天候が大きく崩れる予報がある場合は、登山計画への影響として触れると親切

## Verification

1. 回答で使用した日付がユーザーが求めた対象日(current_datetimeから正しく算出された日)と一致しているか確認する
2. 標高別の気温/風の表に最低3段階の高度データが含まれているか確認する
3. 時間帯別予報の表が一日全体(0時〜24時)をカバーしているか確認する
4. 表内にHTMLタグが含まれていないか、山頂とふもとの天候差に関する注意書きが含まれているか確認する
